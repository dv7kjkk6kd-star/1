Porovnání obchodů robota s plánem od mentora (stránka Plán od mentora): jestli šel robot stejným směrem jako mentor, jestli vstupoval u jeho zón a kdo měl ten den pravdu.

🧠 Co se robot naučil

Robot si u každého obchodu zapamatuje, za jakých podmínek ho udělal. Bere to ze všech částí Kompasu: obchod (model, směr, den, čas vstupu), aplikace (ranní bias a jeho síla, nálada zpráv, fundament, kalendář zpráv, velké zprávy z USA, statistika trhu, futures před otevřením) plán od mentora (jestli čekal stejný směr a jestli vstup byl u jeho zóny) a trh (předchozí den, jak divoký byl, gap, VIX, trend, noc před otevřením, jestli vedl Nasdaq nebo S&P 500). Data z aplikace má jen ze dnů, kdy aplikace běžela, u starších obchodů z backtestu se učí jen z obchodu a trhu. Počítá, ve kterých situacích vydělává a ve kterých prodělává, a ty prodělávající se učí vynechávat. Učí se poctivě: o každém obchodu rozhoduje jen podle obchodů, které byly před ním. Porovnání níže proto ukazuje, co by učení opravdu přineslo.

Robot se začne učit po prvních obchodech. Rychleji to půjde, když dole nahraješ historii obchodů z TradingView.

Všechny obchody

Částky jsou za MNQ (1 bod = 2 $ na kontrakt), bez poplatků. Bias dne je ranní bias z této stránky.

📥 Historie obchodů z TradingView

Aby se robot nemusel učit měsíce, nahraj mu obchody z backtestu. V TradingView otevři Strategy Tester → List of trades, vpravo nahoře klikni na Export (ikona stažení) a ulož jako CSV. Pak ten soubor vyber tady. Ukládá se jen do tohoto prohlížeče (na mobilu ho nahraj znovu). Nový export starý nahradí.

⚙️ Jak robota napojit na TradingView (klikni)
  1. Cloudflare: Workers & Pages → Create → Worker → pojmenuj ho třeba kompas-robot → Deploy → Edit code → smaž vše a vlož obsah souboru worker.js → Deploy.
  2. Úložiště: Storage & Databases → KV → Create namespace (název třeba obchody). Pak ve Workeru Settings → Bindings → Add → KV namespace, Variable name napiš přesně OBCHODY a vyber to úložiště.
  3. Heslo: ve Workeru Settings → Variables and Secrets → Add → typ Secret, název TOKEN, hodnota si vymysli (jen písmena a čísla, aspoň 20 znaků). Nikomu ho neposílej.
  4. TradingView: Nastavení účtu → Security → zapni dvoufázové ověření (bez něj webhooky nejdou).
  5. Alert: otevři graf MNQ1! na 1 minutě se strategií → Alert (budík) → Condition: tvoje strategie → „Order fills only“ → Expiration: Open-ended. V záložce Notifications zaškrtni Webhook URL a vlož https://ADRESA-WORKERU/hook?t=TVŮJ_TOKEN. Do Message vlož text níže a dej Create.
  6. Tady: vlož adresu Workeru (bez /hook a bez tokenu) do pole níže a ulož.

Text do pole Message v TradingView (zkopíruj celý):

{"cas":"{{time}}","akce":"{{strategy.order.action}}","kontrakty":{{strategy.order.contracts}},"cena":{{strategy.order.price}},"pozice":"{{strategy.market_position}}","velikost":{{strategy.position_size}},"popis":"{{strategy.order.comment}}","id":"{{strategy.order.id}}","ticker":"{{ticker}}"}

Strategie běží na serverech TradingView, i když máš počítač vypnutý. TradingView obchoduje jen naoko (papírově), žádné skutečné peníze. Obchody se tu objeví pár sekund po tom, co je strategie udělá.
