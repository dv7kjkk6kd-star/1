🧠 Co se naučilo z ostatních trhů

Robot si statistiku vyzkoušel den po dni na celé historii, jako by ji používal naživo: každý den znal jen to, co bylo do té doby, dal signál a pak zkontroloval, jestli se trefil. Situace, které se naživo trefují, dostávají větší váhu, ty, které se pletou, menší, a když se pletou hodně, vyřadí se. Každý nový den se to celé přepočítá, takže se učí dál.

–trefa verdiktu bez učení, 0 dní
–trefa verdiktu s učením, 0 dní
–s učením za posledních 0 signálů

Zatím žádná situace nedala dost signálů naživo. S každým dnem jich přibývá.
